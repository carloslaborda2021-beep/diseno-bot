# DiseñoBot

Asistente de diseño gráfico web. Genera paletas, pares tipográficos, héroes, botones y checklists, y enlaza los forks de recursos (Tailwind, shadcn/ui, Lucide, Animate.css, Graphite, etc.).

## Cómo usarlo

1. Abre `index.html` en el navegador (doble clic o Live Server).
2. Pulsa un chip o escribe: *paleta editorial café*, *hero SaaS*, *botones*, *checklist*.
3. A la izquierda están tus forks. A la derecha, la vista previa.

No hace falta instalar Node. Carga Tailwind, Animate.css y Lucide por CDN.
